# Sanmitra Solar website

## Plan
- Replace the template home page with a premium, responsive Sanmitra Solar experience, led by a cinematic solar-installation image, clear navigation, interactive savings estimate, and direct enquiry actions.
- Establish the brand system from the brief: deep navy, solar orange and teal accents, Manrope/Inter typography, editorial layouts, accessible motion, and reduced-motion support.
- Build distinct, useful pages for About, Services and service details, Projects, Calculator, Gallery, Blog and Contact, with unique page metadata and working navigation.
- Keep company-specific achievements, projects, testimonials, contact details, and subsidy claims out until verified; label illustrative estimates and demo content clearly.
- Enable Lovable Cloud for persistent enquiries, secure admin sign-in, and manageable site content; implement the admin and data protections after Cloud is available.
- Validate the homepage and core interactions, route metadata, responsive presentation, tests, and preview diagnostics.

## Technical details
- Keep the existing TanStack Start routing and Tailwind v4 design-token conventions.
- Use local frontend state for the calculator and accessible menus/accordions; use Cloud and RLS-protected data for persisted admin and enquiry workflows.
- Prefer generated or bundled solar imagery over hotlinked stock images; avoid adding animation libraries unless they materially improve the experience.
